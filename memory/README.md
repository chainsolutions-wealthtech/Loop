Périmètre unique : `chainsolutions-wealthtech/Loop`.

des sources ou des cibles d'observation distinctes. Ce dossier ne leur
confère aucune autorité croisée.

Cette mémoire est la référence de continuité **du chantier de la PR #2**.

`GOVERNANCE.md`, ni `SOURCE_OF_TRUTH.md`, ni `SUIVI.md` et n'accorde aucun
droit opérationnel. Les autres conversations ne sont pas déclarées importées.

## Conservation

Une nouvelle instruction est inscrite dans la chronologie avec son
périmètre et son statut. Les unités et preuves y renvoient par identifiant.
Un résultat daté reste conservé lorsqu'une observation ultérieure le
contredit ou le dépasse. Les heures non établies ne sont pas ajoutées.

La chronologie couvre les échanges de travail accessibles dans ce fil et
les actions attestées. Les références permettent de retrouver les sources
sans republier les échanges bruts, les données privées, les noms de dépôts
privés ni les chemins sensibles dans ce GitHub public. Les détails de
l'inventaire sont dans le registre privé indexé par `LOOP-INV-20261113-02`.
